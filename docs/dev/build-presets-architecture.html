  • Turbo mode (no signal) → mvp
  • HITL mode (no signal) → production

Stage Modes

  • FULL - All agents for that stage run
  • LEAN - Only essential agents run
  • COMPRESSED - Single agent in reduced mode
  • MINIMAL - Only developers, no oversight
  • SKIP - Stage skipped entirely
