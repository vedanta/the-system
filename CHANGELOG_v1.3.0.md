## Migration Guide

### From v1.2.x to v1.3.0

#### ✅ Backward Compatibility
- All existing commands work unchanged
- All existing workflows compatible
- Project files forward-compatible
- Configuration files unchanged

#### 🆕 New Capabilities Available
```bash
# New app requirements pipeline
/ts-design-turbo --app-spec=requirements/my-app.md
/ts-design-turbo --app-spec=requirements/my-app.json --save-spec=specs/design.yaml

# Enhanced existing commands
/ts-design-turbo input/my-project  # Enhanced with better domain detection
/ts-help                           # Enhanced with improved command discovery
```

#### 📁 Optional New Directories
```bash
mkdir -p requirements/  # For app requirements input files
mkdir -p specs/         # For generated design specifications
```

### From v1.1.x to v1.2.0

#### ✅ All v1.1.x features preserved
#### 🆕 Design Department available as optional Stage 1.5

### From v1.0.x to v1.1.0

#### ✅ All v1.0.x workflows preserved
#### 🆕 Turbo mode, enhanced QA, and utilities added
