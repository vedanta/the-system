# Ask Advisor: $ARGUMENTS

Ask your Founder-Advisor any question about the project.

## Examples

- `ask What's the current blocker?`
- `ask Summarize the architecture decisions`
- `ask What are the risks identified so far?`
- `ask Why did we choose PostgreSQL?`
- `ask What's left to do before green light?`

## Process

1. Read the active project file

2. Use the **founder-advisor** subagent to:
   - Understand the question: "$ARGUMENTS"
   - Find relevant information in the project file
   - Provide a clear, concise answer
   - Reference specific sections/decisions where applicable

3. Keep the response focused and actionable
